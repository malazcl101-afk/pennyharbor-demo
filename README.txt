PENNYHARBOR BUDGET PLANNER

Quick preview
1. Keep every file in this folder together.
2. Double-click index.html to open it in a browser.

For use across phone, tablet and computer
1. Upload the complete folder to GitHub Pages or another HTTPS web host.
2. Open the same published link on Android Chrome, Mac Safari, iPhone or iPad.
3. Android: Chrome menu > Add to Home screen / Install app.
4. iPhone or iPad: Safari Share button > Add to Home Screen.

Important data note
This version stores planner data locally in each browser. It does not automatically
sync data between different devices. Account login and cross-device syncing require
a hosted database and authentication service.
